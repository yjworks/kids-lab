# 키즈랩 (KidLab)

다섯 살부터 혼자 켜서 쓸 수 있는 웹 학습 놀이터. 브라우저만 있으면 되고, 설치도 서버도 필요 없다.
바탕화면에 앱 아이콘이 깔려 있고 누르면 창이 열리는, 아이용 작은 웹OS 형태다.

## 바로 쓰기

`index.html`을 더블클릭하면 끝. GitHub Pages에 올리면 주소만 알려주면 된다.

로컬에서 파일로 바로 열어도 동작하지만, 브라우저에 따라 iframe 제한이 걸릴 수 있어 간단한 서버를 띄우는 쪽이 안전하다.

```
python -m http.server 8000
```

## 휴대폰·PC에 설치하기

앱처럼 설치해 홈 화면이나 바탕화면에서 바로 열 수 있다. 한 번 열어 두면 인터넷이 끊겨도 그대로 돌아간다.

- **안드로이드 크롬**: 주소창 오른쪽 메뉴 → "앱 설치" 또는 화면 위쪽에 뜨는 "⬇️ 설치" 버튼
- **아이폰 사파리**: 공유 버튼 → "홈 화면에 추가"
- **PC 크롬·엣지**: 주소창 오른쪽 설치 아이콘

설치하면 주소창 없이 전체 화면으로 열려 아이가 다른 곳으로 빠져나가기 어렵다.

## 매일 오는 이유

한 번 하고 끝나는 구성이 아니다.

- **오늘의 미션 4개** — 날짜를 시드로 뽑아 매일 바뀐다. 하나 끝낼 때마다 별 3개.
- **단계 자동 조절** — 각 앱의 모드마다 1~5단계가 따로 있다. 75% 이상 맞히면 다음 단계로 올라가 문제 범위와 보기 수가 늘어난다.
- **별과 스티커** — 문제를 맞히면 별이 쌓이고, 별 5개로 스티커를 뽑는다. 도감 50칸을 채우는 게 장기 목표.
- **연속 출석** — 며칠 연달아 했는지 상단에 표시된다.
- **기록이 남는 앱** — 일기, 그림 갤러리, 이야기 책장, 감정 기록, 습관 체크는 계속 쌓인다.

## 계산기와 숫자 블록

**계산기**는 휴대폰 계산기와 같은 배치다. 15자리까지 입력·표시하고, 세 자리마다 쉼표를 찍는다. 누를 때마다, 그리고 답이 나올 때마다 한국말로 읽어 준다. "십이 더하기 칠은 십구" 하는 식이다.

- 0으로 나누면 화면이 빨갛게 바뀌며 "0으로 나눌 수 없어요"라고 쓰고 말해 준다
- 결과가 15자리를 넘으면 "숫자가 너무 커요"라고 알린다
- 0.1 + 0.2 같은 소수 계산도 0.3으로 깔끔하게 나온다
- 쉬운 계산기로 바꾸면 더하기·빼기만 남고 버튼이 커진다
- 계산 기록이 쌓이고, 기록을 누르면 다시 읽어 주고 그 수로 이어서 계산한다
- 숫자 읽기, 자릿값, 큰 수 비교 연습이 함께 들어 있다

**숫자 블록**은 큐브를 쌓아 수를 눈으로 익히는 앱이다. 수마다 고유한 색이 있고 맨 위 블록에 얼굴이 붙는다.

- 블록 쌓기: 버튼으로 하나씩 늘리고 줄이며 수와 이름, 홀짝을 확인한다
- 더하기·빼기: 두 덩어리가 합쳐지고, 빠지는 블록은 흐려진다
- 짝꿍 수: 10을 만들려면 얼마가 더 필요한지 블록으로 본다
- 두 배, 홀수·짝수(둘씩 짝지어 남는 것 보기), 십과 일(10개 묶음 막대)

## 따라 쓰기

숫자 0~9, 한글 자음 14자와 모음 10자, 기본 글자 가~하 14자, 영어 대문자와 소문자 26자씩 모두 100자를 쓴다.

- 획마다 시작점에 번호가 붙고, 열면 쓰는 순서를 한 획씩 그려서 보여 준다
- 회색 본보기를 따라 그린 뒤 "다 썼어요"를 누르면 자동으로 채점한다
- 잘 쓰면 별을 주고 다음 글자로 넘어간다. 쓴 글자에는 체크가 남는다
- 못 지나간 곳은 빨간 점으로 표시해 어디를 빠뜨렸는지 보여 준다
- 획순을 지키면 최고 등급을 주고, 어겨도 통과는 시키되 순서를 일러 준다
- 글자 이름을 한국어나 영어로 읽어 준다

### 채점 방법

글자 선을 일정 간격의 점으로 바꾼 뒤 세 가지를 본다.

1. 아이가 그린 점이 글자 선 가까이 있는가 (밖으로 나가지 않았는가)
2. 글자 선 위의 점을 모두 지나갔는가 (획을 빠뜨리지 않았는가, 획마다 따로 본다)
3. 그린 길이가 글자 길이에 비해 지나치게 길지 않은가 (덧칠과 낙서 거르기)

처음에는 칠해진 넓이만 비교했는데, 그렇게 하면 글자 위에 마구 칠해도 통과했다. 칸을 나눠 세는 방법도 재 봤지만 삐뚤게 쓴 글씨까지 떨어뜨렸다. 선과의 거리로 재는 지금 방법이 둘 다 해결한다.

100자 전부에 열네 가지 경우를 넣어 확인한 결과다.

| 어떻게 썼나 | 통과율 |
|---|---|
| 정확히 따라 씀 | 100% |
| 조금 삐뚤 / 많이 삐뚤 | 100% |
| 두 번 덧그림 | 100% |
| 길이 절반만 그림 | 1% |
| 획 하나 빠뜨림 | 3% |
| 글자 위에 마구 칠하기 | 1% |
| 대각선·지그재그 낙서, 전체 칠하기, 휘갈기기, 점 하나 | 0% |

## 부모용

상단 👨‍👩‍👧 버튼. 곱셈 문제로 아이 진입을 막아 둔다.

- 학습한 날수, 연속 출석, 맞힌 문제 수, 누적 별, 가장 많이 쓴 앱
- 앱별 단계 현황, 이번 달 출석 달력
- 음성 읽어주기와 효과음 on/off
- 프로필 추가·전환 (형제자매용), 데이터 백업(JSON)과 삭제

## 만듦새

- 의존성 없는 순수 HTML/CSS/JS. 빌드 도구도 CDN도 쓰지 않는다.
- 서비스워커가 첫 방문에 32개 파일을 받아 두어 인터넷 없이도 전부 돌아간다. 보여 줄 때는 저장해 둔 것을 쓰고 뒤에서 새 파일을 받아 두므로, 새로 올린 내용은 다음에 열 때 자동으로 반영된다.
- 기록은 전부 브라우저 localStorage에만 남는다. 밖으로 나가는 통신이 없다.
- 음성은 브라우저 내장 Web Speech API, 소리는 Web Audio로 그때그때 합성한다. 오디오 파일이 없어 저장소가 가볍다.
- 그림은 Canvas, 도형과 시계는 인라인 SVG.
- 5세 기준에 맞춰 글자 22px 이상, 터치 대상 최소 110px, 글씨 대신 그림과 소리로 안내한다. 틀려도 별을 뺏지 않고 다시 고르게 한다.

## 구조

```
index.html            바탕화면·창 관리·미션·스티커·부모 설정
apps/write/glyphs.js  따라 쓰기 획 데이터 (100자)
manifest.webmanifest  설치 정보 (이름, 아이콘, 시작 주소)
sw.js                 서비스워커 (오프라인 실행)
icons/                앱 아이콘
shared/kid.js         프로필, 별, 미션, 음성, 효과음, 퀴즈 엔진
shared/app.css        공통 스타일
shared/apps.js        앱 목록
apps/<앱이름>/index.html
```

앱을 하나 더 붙이려면 `apps/새앱/index.html`을 만들고 `<body data-app="새앱">`로 두고, `shared/apps.js`에 한 줄 추가하면 바탕화면에 아이콘이 생긴다. 퀴즈형이면 `KidLab.runQuiz()`에 문제 생성 함수만 넘기면 채점·별·단계 조절이 알아서 돌아간다.

## 확인한 환경

Chromium 기반 브라우저에서 런처와 17개 앱 전체를 자동으로 돌려 콘솔 오류 없음을 확인했다. Windows의 Chrome/Edge 기준으로 만들었고, 음성 읽어주기 품질은 OS에 설치된 한국어 음성에 따라 달라진다.
