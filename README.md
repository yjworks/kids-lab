# 키즈랩 (KidLab)

다섯 살부터 혼자 켜서 쓸 수 있는 웹 학습 놀이터. 브라우저만 있으면 되고, 설치도 서버도 필요 없다.
바탕화면에 앱 아이콘이 깔려 있고 누르면 창이 열리는, 아이용 작은 웹OS 형태다.

## 바로 쓰기

`index.html`을 더블클릭하면 끝. GitHub Pages에 올리면 주소만 알려주면 된다.

로컬에서 파일로 바로 열어도 동작하지만, 브라우저에 따라 iframe 제한이 걸릴 수 있어 간단한 서버를 띄우는 쪽이 안전하다.

```
python -m http.server 8000
```

## 휴대폰·PC에 설치하기

앱처럼 설치해 홈 화면이나 바탕화면에서 바로 열 수 있다. 한 번 열어 두면 인터넷이 끊겨도 그대로 돌아간다.

- **안드로이드 크롬**: 주소창 오른쪽 메뉴 → "앱 설치" 또는 화면 위쪽에 뜨는 "⬇️ 설치" 버튼
- **아이폰 사파리**: 공유 버튼 → "홈 화면에 추가"
- **PC 크롬·엣지**: 주소창 오른쪽 설치 아이콘

설치하면 주소창 없이 전체 화면으로 열려 아이가 다른 곳으로 빠져나가기 어렵다.

## 매일 오는 이유

한 번 하고 끝나는 구성이 아니다.

- **오늘의 미션 4개** — 날짜를 시드로 뽑아 매일 바뀐다. 하나 끝낼 때마다 별 3개.
- **단계 자동 조절** — 각 앱의 모드마다 1~5단계가 따로 있다. 75% 이상 맞히면 다음 단계로 올라가 문제 범위와 보기 수가 늘어난다.
- **별과 스티커** — 문제를 맞히면 별이 쌓이고, 별 5개로 스티커를 뽑는다. 도감 50칸을 채우는 게 장기 목표.
- **맞고 틀림이 분명하다** — 틀리면 화면 가운데에 큰 ✗ 가 뜨고 "아니에요"라고 말해 준다. 고른 칸에는 ✗ 표시가 남고, 문제 위에 빨간 띠로 "다시 골라 보세요"가 나온다. 두 번 틀리면 정답 칸이 노랗게 깜빡인다. 맞히면 초록 띠와 ○ 표시가 붙는다.
- **연속 출석** — 며칠 연달아 했는지 상단에 표시된다.
- **기록이 남는 앱** — 일기, 그림 갤러리, 이야기 책장, 감정 기록, 습관 체크는 계속 쌓인다.

## 읽기 경로 (문해력)

낱자 → 받침 → 낱말 → 문장 → 책 순서로 이어진다. 부모님 설정에 지금 어느 단계인지 표시된다.

- **받침 놀이** — 한글 놀이가 초성+중성까지만 다루던 빈칸을 채운다. 받침은 소리 나는 일곱 가지(ㄱㄴㄷㄹㅁㅂㅇ)로 가르치고, ㅅ·ㅈ·ㅊ·ㅌ·ㅎ은 끝에서 [ㄷ] 소리가 난다고 알려 준다. 겹받침은 넣지 않았다.
- **낱말 만들기** — 글자 카드를 끌지 않고 차례로 누른다(5세 손과 휴대폰에 맞춤). 헷갈리는 카드는 첫소리나 모음이 같은 글자로 섞는다.
- **문장 읽기** — 문장은 자동으로 읽어 주지 않는다. 읽는 연습이기 때문이다. 대신 낱말을 하나씩 누르면 그 낱말만 읽어 주고, "문장 듣기" 단추도 있다. 오답 그림은 주어나 목적어 하나만 바꿔 두 낱말을 모두 읽어야 맞힐 수 있게 했다.
- **읽기 책** — 처음 네 권이 열려 있고, 한 권을 읽을 때마다 다음 책이 열린다. 끝까지 넘기면 별 2개와 도장, 질문은 덤이다.
- **옛이야기** — 토끼와 거북이, 해님 달님, 흥부와 놀부, 금도끼 은도끼, 해와 바람, 양치기 소년, 서울 쥐와 시골 쥐, 의좋은 형제. 5세 눈높이로 새로 썼고(무서운 장면은 순하게), 처음부터 모두 열려 있다.
- **읽기 지문** — 학년마다 3편씩, 갈래가 겹치지 않게 골랐다. 문제에는 [사실]·[중심]·[낱말]·[추론]·[짜임] 표시가 붙어 어떤 힘을 묻는지 보인다. 문제를 푸는 동안 "📖 글 다시 보기"로 언제든 글을 볼 수 있고, 지문마다 최고 점수가 남는다. 모든 글은 이 앱을 위해 새로 썼다(교과서 지문을 옮기지 않았다).
- **듣고 맞히기** — 글을 못 읽어도 되는 청해 경로. 3단계부터 "글 보기"로 글자를 같이 볼 수 있다.
- 낱말 창고(`shared/words.js`) 159개는 이모지 한 개로 뜻이 분명한 것만 골랐고, 같은 그림이 두 낱말에 쓰이지 않는다.
- 문제 생성기는 단계 1~5마다 150~200문제씩, 모드 37개(영단어 5단계 포함)에서 29,000문제를 만들어 정답 1개·보기 중복 없음·빈 값 없음·괄호 조사 없음을 확인했다.

## 우리말·고전

- **우리말 탐험** — 속담·사자성어·관용어는 50개씩. 관용어("발이 넓다", "시치미를 떼다" 등)는 4단계부터 뜻을 보고 관용어를 고르는 문제가 섞인다. 낱말은 학년 묶음(초1~2, 초3~4, 초5~6)마다 20개. 낮은 단계에서는 아래 학년 낱말만 나오고, 4단계부터 "뜻 보고 낱말 고르기"가 섞인다. 뜻이 비슷해 함께 보기로 나오면 헷갈리는 짝(일석이조·금상첨화, 우공이산·대기만성 등)은 한 문제에 같이 내지 않는다. 뜻풀이는 사전을 옮기지 않고 이 앱을 위해 쉬운 말로 새로 썼다. 답을 맞히면 **풀이 카드**가 떠서 짚고 넘어간다: 낱말·관용어는 뜻과 예문, 속담은 뜻과 생활 예문, 사자성어는 글자마다 훈음·글자 그대로의 풀이·예문을 보여 주고 읽어 준다. 저절로 넘어가지 않고 아이가 "다음 ▶"을 눌러야 다음 문제로 간다.
- **고전 한 문장** — 저작권이 끝난 원전에서 출처가 분명한 문장만 골랐다. 논어 19, 맹자 4, 대학 2, 중용 1, 예기 1, 명심보감 9, 노자 3, 순자 1, 탈무드(피르케이 아보트) 6, 이솝 우화 6 — 모두 52문장. 뜻이 비슷한 문장(남을 보고 나를 돌아보라는 세 문장)은 뜻 맞히기 보기에 함께 내지 않는다. "오늘의 한 문장"은 날짜로 정해져 하루 종일 같고 날마다 바뀐다. 한문에는 읽기(음)를 달았다. 뜻 맞히기에서 맞히면 읽기·원문·뜻·생활 속 풀이를 담은 풀이 카드가 뜬다.
- **천자문** — 첫 16구절(天地玄黃~菜重芥薑, 64자). 글자마다 훈음, 구절마다 풀이. 단계가 오를 때마다 4구절씩 문제 범위가 넓어진다.
- **탈무드 지혜 이야기** — 혀 이야기, 세 친구, 포도밭의 여우, 나무 심는 할아버지, 삼 형제와 마법 사과. 널리 전해지는 줄거리를 5~7세 눈높이로 새로 썼다.

## 필사 (자유 따라 쓰기)

고전 문장과 천자문은 글자가 많아 글자마다 획 데이터를 만들 수 없다. 그래서 필순 없이 글꼴 모양 위에 따라 쓰는 방식(`shared/copy.js`)을 따로 두었다. 쓰는 것이 목적이라 채점은 느슨하다.

- 글자 모양을 48×48 칸으로 나눠, 아이가 그은 선이 글자 칸의 절반 이상을 덮고, 선의 대부분(62% 이상)이 글자 근처에 있고, 글자보다 2.6배 넘게 칠하지 않았으면 통과.
- 앱의 판정 함수에 32자(한글·한자·영문)를 여러 방식으로 그려 넣은 결과: 제대로 따라 씀 32/32, 삐뚤게 씀 32/32 통과. 대각선 낙서 5/32, 절반만 씀 3/32, 칸 전체 칠하기 0/32, 점 하나 0/32.
- 공백과 문장부호는 건너뛴다. 다 쓰면 필사 노트에 날짜가 남는다.

## 요즘 교육 흐름에 맞춘 앱

- **진짜일까? (미디어 리터러시)** — 모든 문제에 까닭이 붙는다. 맞히면 "💡 광고는 사라고 하는 글이에요" 같은 한 줄이 3초간 남는다.
- **AI 가르치기** — 로보는 "가장 닮은 예를 따라 하는" 방식(최근접 이웃)으로 배운다. 아이가 붙인 이름표 그대로 배워서, 반대로 가르치면 반대로 대답한다. 시험 마지막에는 펭귄(날개·깃털이 있지만 못 난다)이 나와 AI도 틀릴 수 있음을 보여 준다. "로보의 실수"는 빨간 사과만 배운 로보가 초록 사과를 사과가 아니라고, 빨간 공을 사과라고 하는 과정을 단계별로 보여 준다. 모델·서버 없이 기기 안에서 돈다.
- **내 저금통** — 날마다 용돈 1,000원을 받고 가게 유혹(사탕·스티커 등)을 참을지 고른다. 목표를 사면 "다 참았으면 며칠 만에 살 수 있었어요"를 알려 준다. 이자·금리 같은 숫자는 넣지 않았다.
- **지구 지킴이** — 분리배출은 지역마다 다른 품목(우유팩·스티로폼·건전지)을 빼고 공통 규칙만 넣었다(달걀 껍데기·닭 뼈·복숭아 씨는 일반 쓰레기). 먹이 문제는 헷갈리는 잡식 동물을 빼고, 보기를 반대쪽 먹이(풀 먹는 동물에게는 고기, 고기 먹는 동물에게는 풀)에서만 골랐다.
- **세계 여행** — 국기는 Windows에서 이모지로 보이지 않아서 flag-icons(MIT 라이선스)의 SVG를 그대로 담았다. 인사말은 한국어 읽기로 먼저 읽고, "○○ 말로 듣기"로 원어 음성을 들을 수 있다(기기에 그 언어 음성이 없으면 비슷하게 읽힌다). 영어권 나라는 인사말이 겹쳐서 인사말 문제에서 뺐다.
- **쌓기나무** — 뒤 기둥이 앞 기둥보다 낮지 않게 만들어 모든 기둥의 윗면이 보이고, 떠 있는 나무가 없다. 아래에 가려진 나무까지 세게 한다. "앞·옆에서 본 모양"은 그림의 빨간 화살표 쪽에서 본 모양을 고른다. 칸마다 그 줄에서 가장 높은 기둥의 높이가 보이며, 다른 쪽에서 본 모양·좌우를 뒤집은 모양을 오답 보기로 넣는다.
- **칠교** — 조각을 끌어 같은 모양·방향의 자리 가까이 놓으면 딱 붙는다. 처음 세 문제는 조각 선이 보이고, 그다음은 "💡 선 보기"로 켤 수 있다. 22가지를 조각 수에 따라 쉬움(2~3)·보통(4~5)·어려움(6)·칠교 7조각 모두로 묶었다. 새로 넣은 15가지는 진짜 칠교 조각 크기(평행사변형 포함)이고, 칠교 풀이 프로그램으로 조각이 겹치지 않고 빈틈 없이 변끼리 이어지는지 확인한 좌표만 썼다. 마우스로 22가지 모두, 손가락으로 2가지를 실제 입력으로 끝까지 맞춰 확인한다.
- **이야기 만들기** — 모험·우주 탐험·바닷속 여행·생일 파티·꼬마 탐정·마법 학교·공룡 시대로·숲속 운동회 8가지. 단계는 짧은 이야기(카드 4장), 긴 이야기(카드 5~6장), 작가 되기(카드 + 주인공 이름·대사·마지막 문장을 직접 쓰기). 조사는 고른 낱말과 지은 이름의 받침에 맞춰 붙는다. 예전에 책장에 넣은 이야기도 그대로 열린다.
- **이야기 수학** — 받침 없는 이름만 써서 조사가 자연스럽고, 3단계부터 필요 없는 수가 섞인다. 맞히면 식을 읽어 준다.
- **자판 연습** — 운영체제 한/영 상태와 관계없이 눌린 자판 자리로 판정하고, 한글은 앱 안의 두벌식 조합기로 글자를 만든다(겹모음·겹받침 포함 12개 낱말로 조합 확인). 휴대폰에서는 화면 자판을 누른다.

## 엘리베이터 타기

생활 습관 안에 있다. ▲▼로 부르기 → 타기 → 층 버튼 찾기 → 닫힘 → 이동 → 내리기를 직접 해 본다. 탈 때마다 건물이 바뀐다.

- **아파트** — 1층부터, 가끔 옥상(RF)
- **호텔** — 로비(L)가 1층 자리, 그 위로 2층부터
- **영국식 건물** — 땅 층이 G(그라운드), 그 위가 1층
- **백화점** — 지하 B1~B3와 옥상(RF)

처음 나오는 표시(L·G·RF·B)는 뜻을 알려 준다. 단계가 오르면 층이 늘고 안전 상황이 나온다: 문이 닫힐 때 친구가 뛰어오면 열림 버튼, 멈추면 비상벨, 불이 나면 계단으로 땅 층까지. 틀리면 왜 위험한지 말해 주고 다시 고르게 한다.

## 계산기와 숫자 블록

**계산기**는 휴대폰 계산기와 같은 배치다. 15자리까지 입력·표시하고, 세 자리마다 쉼표를 찍는다. 누를 때마다, 그리고 답이 나올 때마다 한국말로 읽어 준다. "십이 더하기 칠은 십구" 하는 식이다.

- 0으로 나누면 화면이 빨갛게 바뀌며 "0으로 나눌 수 없어요"라고 쓰고 말해 준다
- 결과가 15자리를 넘으면 "숫자가 너무 커요"라고 알린다
- 0.1 + 0.2 같은 소수 계산도 0.3으로 깔끔하게 나온다. 100,000,000,000,000 + 3 처럼 큰 수에 작은 수를 더해도 자릿수가 그대로 산다
- 쉬운 계산기로 바꾸면 더하기·빼기만 남고 버튼이 커진다
- 계산 기록이 쌓이고, 기록을 누르면 다시 읽어 주고 그 수로 이어서 계산한다
- 숫자 읽기, 자릿값, 큰 수 비교 연습이 함께 들어 있다

**숫자 블록**은 큐브를 쌓아 수를 눈으로 익히는 앱이다. 수마다 고유한 색이 있고 맨 위 블록에 얼굴이 붙는다.

- 블록 쌓기: 버튼으로 하나씩 늘리고 줄이며 수와 이름, 홀짝을 확인한다
- 더하기·빼기: 두 덩어리가 합쳐지고, 빠지는 블록은 흐려진다
- 짝꿍 수: 10을 만들려면 얼마가 더 필요한지 블록으로 본다
- 두 배, 홀수·짝수(둘씩 짝지어 남는 것 보기), 십과 일(10개 묶음 막대)

## 따라 쓰기

숫자 0~9, 한글 자음 14자와 모음 10자, 기본 글자 가~하 14자, 영어 대문자와 소문자 26자씩 모두 100자를 쓴다. 따로 떨어진 앱이 아니라 과목별로 나눠 두었다. 한글은 한글 놀이에, 영어는 영어 놀이에, 숫자는 수학 놀이에 들어 있다. 엔진은 `shared/trace.js` 하나를 세 앱이 같이 쓰고, 진도도 한곳에 모아 둬서 어디서 열든 이어진다.

- 획마다 시작점에 번호가 붙고, 열면 쓰는 순서를 한 획씩 그려서 보여 준다
- 회색 본보기를 따라 그린 뒤 "다 썼어요"를 누르면 자동으로 채점한다
- 잘 쓰면 별을 주고 다음 글자로 넘어간다. 쓴 글자에는 체크가 남는다
- 못 지나간 곳은 빨간 점으로 표시해 어디를 빠뜨렸는지 보여 준다
- 획순을 지키면 최고 등급을 주고, 어겨도 통과는 시키되 순서를 일러 준다
- 글자 이름을 한국어나 영어로 읽어 준다

### 채점 방법

글자 선을 일정 간격의 점으로 바꾼 뒤 세 가지를 본다.

1. 아이가 그린 점이 글자 선 가까이 있는가 (밖으로 나가지 않았는가)
2. 글자 선 위의 점을 모두 지나갔는가 (획을 빠뜨리지 않았는가, 획마다 따로 본다)
3. 그린 길이가 글자 길이에 비해 지나치게 길지 않은가 (덧칠과 낙서 거르기)

처음에는 칠해진 넓이만 비교했는데, 그렇게 하면 글자 위에 마구 칠해도 통과했다. 칸을 나눠 세는 방법도 재 봤지만 삐뚤게 쓴 글씨까지 떨어뜨렸다. 선과의 거리로 재는 지금 방법이 둘 다 해결한다.

확인은 판정식을 흉내 낸 스크립트가 아니라, 실제 앱을 띄워 손가락 입력으로 151자(숫자·자모·가~하·받침 글자·영문·한자)를 하나씩 그려 보고 앱이 내린 판정을 읽는 방식으로 한다. 쓰기는 써 보는 것이 목적이라 판정을 넉넉하게 두고 낙서만 거른다.

| 어떻게 썼나 | 통과율 |
|---|---|
| 흔들리고 치우치게 그림 (±3·±4칸, 151자) | 100% |
| 아주 삐뚤게 그림 (±6·±8칸, 151자) | 98% |
| 길이 절반만 그림 | 13~33% |
| 획 하나 빠뜨림 | 14~17% |
| 대각선 낙서, 글자 위 마구칠 | 4~17% |
| 지그재그 낙서, 칸 전체 칠하기, 점 하나 | 0% |

통과 조건: 그린 선의 62% 이상이 글자 선에서 10칸 안, 글자 선의 75% 이상(획마다 60% 이상)을 12칸 안에서 지나감, 그린 길이가 글자 길이의 3배 이하. 획순까지 지키고 더 정확하면 최고 등급.

## 부모용

상단 👨‍👩‍👧 버튼. 곱셈 문제로 아이 진입을 막아 둔다.

- 학습한 날수, 연속 출석, 맞힌 문제 수, 누적 별, 가장 많이 쓴 앱
- 앱별 단계 현황, 이번 달 출석 달력
- 음성 읽어주기와 효과음 on/off
- 프로필 추가·전환 (형제자매용), 데이터 백업(JSON)과 삭제

## 화면 설계 기준

- 폰에서는 앱 창 제목줄이 앱 이름과 닫기를 맡고, 앱 안쪽 머리말은 감춘다. 이 46px이 내용 영역으로 돌아간다 (내용 시작 위치 144px → 102px).
- 누르는 것은 최소 44px, 자주 쓰는 뒤로 버튼은 56px로 잡는다.
- 글씨 대비는 본문 4.5:1 이상을 목표로 한다. 흐린 회색(#888, #999)은 쓰지 않는다.
- 상단 알약은 화면이 좁아지면 순서대로 사라진다(시계 → 연속 출석 → 이름 → 도장). 절대 겹치지 않는다.

## 만듦새

- 의존성 없는 순수 HTML/CSS/JS. 빌드 도구도 CDN도 쓰지 않는다.
- 서비스워커가 첫 방문에 32개 파일을 받아 두어 인터넷 없이도 전부 돌아간다. 보여 줄 때는 저장해 둔 것을 쓰고 뒤에서 새 파일을 받아 두므로, 새로 올린 내용은 다음에 열 때 자동으로 반영된다.
- 기록은 전부 브라우저 localStorage에만 남는다. 밖으로 나가는 통신이 없다.
- 음성은 브라우저 내장 Web Speech API, 소리는 Web Audio로 그때그때 합성한다. 오디오 파일이 없어 저장소가 가볍다.
- 그림은 Canvas, 도형과 시계는 인라인 SVG.
- 5세 기준에 맞춰 글자 22px 이상, 터치 대상 최소 110px, 글씨 대신 그림과 소리로 안내한다. 틀려도 별을 뺏지 않고 다시 고르게 한다.

## 구조

```
index.html            바탕화면·창 관리·미션·코스·스티커·부모 설정
guide.html            사용 가이드 (앱 안내·코스 계획표)
shared/courses.js     학습 코스 10개
shared/glyphs.js      따라 쓰기 획 데이터 (100자)
shared/trace.js       따라 쓰기 엔진 (한글·영어·수학·한자 앱이 함께 쓴다)
shared/copy.js        필사 엔진 (필순 없이 글꼴 위에 따라 쓰기)
shared/classics.js    천자문·고전 명구 자료
apps/world/flags.js   국기 SVG (flag-icons, MIT)
manifest.webmanifest  설치 정보 (이름, 아이콘, 시작 주소)
sw.js                 서비스워커 (오프라인 실행)
icons/                앱 아이콘
shared/kid.js         프로필, 별, 미션, 음성, 효과음, 퀴즈 엔진
shared/app.css        공통 스타일
shared/apps.js        앱 목록
apps/<앱이름>/index.html
```

앱을 하나 더 붙이려면 `apps/새앱/index.html`을 만들고 `<body data-app="새앱">`로 두고, `shared/apps.js`에 한 줄 추가하면 바탕화면에 아이콘이 생긴다. 퀴즈형이면 `KidLab.runQuiz()`에 문제 생성 함수만 넘기면 채점·별·단계 조절이 알아서 돌아간다.

## 전수조사 테스트

`tests/TESTPLAN.md`에 케이스 42개(정적 검사 9, 앱 실행 3, 문제 생성 5, 상호작용 18, 런처 7)와 합격 기준이 있다. `node tests/run.js`로 한 번에 돌리고, `node tests/run.js S06,R02`처럼 골라 돌릴 수도 있다. 결과는 `tests/report.md`. Playwright와 Chromium이 필요하다(경로는 `PLAYWRIGHT` 환경 변수로 바꿀 수 있다).

- 모든 앱의 모든 메뉴(214개)를 폰 화면에서 열고, 퀴즈는 첫 문제를 일부러 틀려 ✗ 표시를 확인한 뒤 끝까지 푼다.
- 퀴즈 모드 119개에서 단계 1~5마다 150문제씩 89,250문제를 만들어 정답 수, 보기 중복, 빈 값, 조사, 뜻(식의 값, 그려진 나무 수, 단가)을 검사한다.
- Windows 10에서 네모로 보이는 새 이모지(Emoji 13.0 이상)는 쓰지 않는다.
- 조사는 `KidLab.josa(낱말, '을/를')`로 붙인다. 낱말 뒤에 조사를 직접 붙이면 S08이 잡아낸다.

## 확인한 환경

Chromium 기반 브라우저에서 런처와 43개 앱 전체를 자동으로 돌려 콘솔 오류 없음을 확인했다. Windows의 Chrome/Edge 기준으로 만들었고, 음성 읽어주기 품질은 OS에 설치된 한국어 음성에 따라 달라진다.
